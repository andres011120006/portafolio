Backend · Proyecto destacado

API de detección de fraude transaccional

API REST que puntúa transacciones y responde según el nivel de riesgo. Valida los datos con Pydantic v2, utiliza un modelo RandomForest y se empaqueta en una imagen Docker multi-stage. El proyecto incluye logs en JSON, medición del tiempo de respuesta y CI con GitHub Actions; contempla despliegue en Google Cloud Run o AWS Lambda.

  • FastAPI
  • scikit-learn
  • Pydantic v2
  • Docker
  • Cloud Run

  • GitHub Actions
