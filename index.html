Proyecto destacado

API de detección de fraude transaccional

API REST en tiempo real que puntúa cada transacción y responde según el nivel de riesgo. Valida los datos con Pydantic v2, usa un modelo RandomForest y se empaqueta en un contenedor Docker multi-stage listo para Google Cloud Run o AWS Lambda, con logs en JSON, medición de tiempo de respuesta y CI en GitHub Actions.

  • FastAPI
  • scikit-learn
  • Pydantic v2
  • Docker
  • Cloud Run
  • AWS Lambda
  • GitHub Actions
Ver código en GitHub
POST /v1/predict

Cada transacción recibe un risk_score entre 0 y 1 y una decisión:

00.400.80
APPROVED riesgo menor a 0.40
FLAGGED de 0.40 a 0.79, para revisión
REJECTED riesgo de 0.80 o más
  1. Cliente
  2. Cloud Run o Lambda
  3. Validación con Pydantic
  4. Modelo RandomForest
  5. Decisión
  6. GitHub Actions ejecuta las pruebas y construye la imagen en cada push.
